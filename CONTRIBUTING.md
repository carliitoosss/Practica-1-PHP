
# Guía de contribución

Gracias por tu interés en colaborar en esta
práctica de introducción a PHP.

## Requisitos

Para colaborar en este proyecto es recomendable
tener conocimientos básicos de:

- PHP.
- HTML.
- Git y GitHub.
- Markdown.

## Cómo contribuir

1. Realizar un fork del repositorio.
2. Crear una rama para los cambios.
3. Realizar las modificaciones necesarias.
4. Comprobar que los ejercicios funcionan.
5. Enviar una Pull Request con los cambios.

## Normas del proyecto

- Mantener el código organizado.
- Utilizar nombres de variables descriptivos.
- Añadir comentarios cuando sean necesarios.
- No eliminar funcionalidades existentes sin justificación.
- Documentar los cambios importantes.

## Comunicación de errores

Si encuentras algún error, puedes comunicarlo
mediante una incidencia (Issue) en GitHub,
explicando el problema y cómo reproducirlo.
